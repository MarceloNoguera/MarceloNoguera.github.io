01 — Selected work

A grading system I built end to end.

From the model contract to the container running in production.

live multimodal deployed

Device Condition Grader

Upload a photo of a phone, laptop or tablet and the system returns a physical condition grade, a confidence score, the specific defects and positives it detected, and an estimated trade-in price band.

A four-grade condition taxonomy — Flawless / Good / Used / Damaged — with written criteria the model is held to, rather than free-form description.
Strict structured output: the vision model is constrained to a JSON contract, validated server-side before it can reach the pricing layer.
Device recognition — type, brand and model inferred from the image, used to select the matching pricing matrix.
Containerised FastAPI service on Railway, with a static front end served from GitHub Pages against the same API.
Why it matters: a deployed implementation of photo-based condition grading and device recognition — the exact problem shape of trade-in and recommerce platforms. Built end to end using an AI coding agent as the primary development tool.

03 — Background

The instinct that finds an auth bypass is the one that asks where a model quietly fails.

Seven years of adversarial work across banking, critical infrastructure and national institutions taught me to distrust the happy path — to look for the edge input, the silent failure, the gap between what a report claims and what actually reproduces.

That is the same discipline a grading model needs: honest evaluation, low-confidence cases routed for review, and a clear-eyed view of where a benchmark stops resembling the real distribution.
