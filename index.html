Device Condition Grader

A grading service for used electronics. Upload a photo of a phone, laptop or tablet and the system returns a physical condition grade, a confidence score, the specific defects and positives detected, and an estimated trade-in price band.

A four-grade condition taxonomy — Flawless / Good / Used / Damaged — with written criteria the model is held to, rather than free-form description.
Strict structured output: the vision model is constrained to a JSON contract, validated server-side before it can reach the pricing layer.
Device recognition — type, brand and model inferred from the image and used to select the matching pricing matrix.
Containerised FastAPI service on Railway, with a static front end served from GitHub Pages against the same API.
Why it matters: a working, deployed implementation of photo-based condition grading and device recognition — the exact problem shape of trade-in and recommerce platforms. Built end to end using an AI coding agent as the primary development tool.
