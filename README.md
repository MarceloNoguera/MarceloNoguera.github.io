# marcelonoguera.github.io

Personal portfolio — Marcelo Antonio Noguera Plata, Senior Cybersecurity Specialist
working in offensive security and applied AI.

Live at **https://marcelonoguera.github.io**

## Structure

```
.
├── index.html    # the whole site — no build step, no framework
├── assets/
│   ├── nasa-vdp-letter.jpeg
│   └── Marcelo-Noguera-CV.pdf
└── README.md
```

Static HTML and CSS, served by GitHub Pages from the root of `main`. Inter and
JetBrains Mono are loaded from Google Fonts; nothing else is fetched at runtime.

## Featured project

[condition-grader](https://github.com/MarceloNoguera/condition-grader) — multimodal
LLM grading service for used electronics. FastAPI backend on Railway, static front end
on GitHub Pages.
